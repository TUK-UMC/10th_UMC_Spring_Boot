###  과제 제출 가이드

스터디는 **주차별 브랜치 릴레이 방식**을 사용합니다.  
본인 이름의 폴더 내에서 작업을 진행해 주세요.

### 1. 첫 시작 (4주차)

- **브랜치 생성**  
  `main` 브랜치에서 본인의 과제 브랜치를 생성합니다.  
  규칙: `feat/week4-별명`  
  예: `feat/week4-toy`

- **PR 생성**  
  본인 폴더 작업 후 `main` 브랜치로 Pull Request를 보냅니다.  
  제목: `[4주차] 워크북 미션-별명`

### 2. 과제 이어가기 (5주차 ~)

- **중요**  
  `main`이 아니라 **이전 주차 브랜치**에서 새 브랜치를 생성해야 합니다.  
  예: `feat/week4-toy` → `feat/week5-toy`

- **PR 생성**  
  작업 완료 후 동일하게 `main` 브랜치로 PR을 보냅니다.  
  제목: `[5주차] 워크북 미션-별명`

### 3. 리뷰 및 피드백

- 파트장의 리뷰 확인 후, 해당 브랜치에서 수정하여 다시 `push`합니다.
- 모든 PR은 **Merge하지 않고 Open 상태**로 유지합니다.

## 주의사항

- `main` 브랜치에 직접 `push` 또는 `merge` 금지
- 새로운 주차 브랜치를 생성할 때, 반드시 이전 주차 브랜치 기준인지 확인
